한마루 익스텐션 개인정보처리방침

시행일: 2026년 10월 12일 · 적용 대상: Chrome 확장 프로그램 "한마루 익스텐션"(ID: jlpofmdhaepcipgamkpidolfhlpbabhm)

한마루 익스텐션(이하 "확장 프로그램")은 HL그룹 사내 업무 포털 "한마루"(ep.hlcompany.com)의 일일보고·헬프데스크 업무를 돕는 도구입니다. 이 방침은 확장 프로그램이 어떤 데이터를 수집·처리·보관·공유하는지 설명합니다.

1. 수집·처리하는 데이터

확장 프로그램은 한마루 로그인 아이디·비밀번호를 읽거나 저장하지 않습니다. 사용자가 이미 로그인한 브라우저 세션으로 한마루 페이지를 조회합니다. 방문 기록, 위치 정보, 금융 정보, 건강 정보는 수집하지 않으며, 광고나 사용 통계(분석) 목적의 추적도 하지 않습니다.

2. 처리 방법

  • 대부분의 처리는 사용자의 브라우저 안에서 이루어집니다.
  • AI 기능(번역, 지식베이스 초안·조언, 업무 보고서 생성 등)은 사용자가 설정에서 본인의 Google Gemini API 키를 등록한 경우에만 동작합니다. 이때 해당 기능에 필요한 텍스트와 이미지(헬프데스크 내용, 첨부 이미지, 번역할 문장, 업무 보고 데이터)가 Google Gemini API로 전송됩니다.
  • 지식베이스 서버 동기화는 사용자가 사내 지식베이스 서버 API 키를 등록한 경우에만 동작합니다. 등록되어 있으면 30분마다 서버의 변경 여부를 확인해 내려받고, 3일마다 로컬 지식베이스 항목을 서버에 업로드하며, 사용자가 직접 업로드·다운로드할 수도 있습니다.
  • 공휴일 확인을 위해 공휴일 API(date.nager.at)에 연도와 국가 코드(KR)만 전송합니다. 개인 정보는 포함되지 않습니다.

3. 보관

  • 모든 데이터는 사용자 PC의 브라우저 저장소(chrome.storage.local)에 저장되며, 개발자가 운영하는 서버로 전송되지 않습니다.
  • 보관 기간: 사용자가 확장 프로그램 화면에서 삭제하거나 확장 프로그램을 제거할 때까지 보관됩니다. 확장 프로그램을 제거하면 저장된 데이터는 모두 삭제됩니다. 로컬 지식베이스는 최대 500건까지만 보관합니다.
  • 사내 지식베이스 서버에 업로드된 항목은 해당 서버를 운영하는 회사(HL그룹)의 정책에 따라 보관됩니다.

5. 사용자의 선택과 삭제

  • AI 기능과 지식베이스 서버 동기화는 선택 사항입니다. API 키를 등록하지 않거나 삭제하면 외부 전송이 이루어지지 않습니다.
  • 할 일, 지식베이스 항목, API 키, 설정은 확장 프로그램 관리 화면에서 언제든 수정·삭제할 수 있습니다.
  • 확장 프로그램을 제거하면 브라우저에 저장된 모든 데이터가 삭제됩니다.

6. 보안

API 키와 데이터는 사용자 브라우저에만 저장되며, 개발자가 접근할 수 없습니다. 외부 전송은 위 4항에 적힌 서비스로만 이루어집니다.

Hanmaru Extension Privacy Policy

Effective date: October 12, 2026 · Applies to the Chrome extension "한마루 익스텐션 (Hanmaru Extension)" (ID: jlpofmdhaepcipgamkpidolfhlpbabhm)

Hanmaru Extension (the "Extension") helps employees with daily reports and help-desk tasks on "Hanmaru" (ep.hlcompany.com), the internal work portal of HL Group. This policy explains what data the Extension collects, how it is processed, where it is stored, and with whom it is shared.

The Extension does not read or store Hanmaru login IDs or passwords; it uses the browser session the user is already signed in with. It does not collect browsing history, location, financial, or health information, and it does not track users for advertising or analytics.

2. How data is processed

  • Most processing happens locally in the user's browser.
  • AI features (translation, knowledge base drafts/advice, work report generation, etc.) run only if the user registers their own Google Gemini API key. When used, the text and images required for that feature (help-desk content, attached images, text to translate, work report data) are sent to the Google Gemini API.
  • Knowledge base server sync runs only if the user registers an internal knowledge base server API key. When registered, the Extension checks the server for updates every 30 minutes, uploads local knowledge base entries every 3 days, and also syncs when the user triggers it manually.
  • Public holiday lookup sends only the year and country code (KR) to the holiday API (date.nager.at). No personal data is included.

3. Storage and retention

  • All data is stored in the browser's local extension storage (chrome.storage.local) on the user's PC. Nothing is sent to servers operated by the developer.
  • Data is kept until the user deletes it in the Extension or uninstalls the Extension; uninstalling removes all stored data. The local knowledge base keeps at most 500 entries.
  • Entries uploaded to the internal knowledge base server are retained according to the policies of the company that operates it (HL Group).

4. Sharing with third parties

We do not sell user data. Data is shared only as follows:

5. User choices and deletion

  • AI features and knowledge base server sync are optional. If no API key is registered (or it is removed), no data is sent to those services.
  • To-do items, knowledge base entries, API keys, and settings can be edited or deleted at any time in the Extension's management page.
  • Uninstalling the Extension deletes all data stored in the browser.

6. Security

API keys and data are stored only in the user's browser and are not accessible to the developer. Data is transmitted only to the services listed in Section 4.
